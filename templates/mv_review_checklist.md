## 2. Baseline Verification

### IGA Comparison
- [ ] Baseline values match IGA (Investment Grade Audit)
- [ ] Baseline period correctly identified
- [ ] Independent variables documented (weather, occupancy, etc.)
- [ ] Any baseline adjustments justified and documented

### Regression Models (Option C)
- [ ] Model equation provided
- [ ] R² value acceptable (>0.75 preferred)
- [ ] CV(RMSE) within limits (<25% monthly, <15% daily)
- [ ] Residual analysis performed
- [ ] Model coefficients physically reasonable

---

## 3. Savings Calculations by ECM Type

### Lighting (typically Option A)
- [ ] Fixture counts verified or stipulated
- [ ] Wattage reductions documented
- [ ] Operating hours - stipulated or measured
- [ ] Interactive effects considered (HVAC)
- [ ] Spot measurements current (within 12 months)

### HVAC Equipment (typically Option B)
- [ ] Metering equipment calibrated
- [ ] Data completeness (>90% of hours)
- [ ] Performance curves/efficiency verified
- [ ] Control sequences operating as designed
- [ ] Weather normalization applied correctly

### Whole Building (Option C)
- [ ] Utility bills reconciled to meter data
- [ ] Weather data source documented (TMY vs actual)
- [ ] Non-routine adjustments itemized
- [ ] Savings uncertainty calculated
- [ ] Results within expected range

### Water Conservation
- [ ] Flow rate measurements current
- [ ] Fixture counts verified
- [ ] Usage factors reasonable
- [ ] Irrigation separately metered (if applicable)
