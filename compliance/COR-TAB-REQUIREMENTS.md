# COR File Tab Requirements

Per PIB 21-05, FAR 4.803(b), GSAM 504.802, and GSA COR Desk Guide (Appendix F)

## Standard Tab Structure (Tabs 01-08)

### Tab 01 — COR Designation & Authority
- COR Designation Letter (signed, current)
- FAC-COR Level II certification documentation
- Delegation of authority scope and limitations
- Supervisor designation (if applicable)

### Tab 02 — Contract Documents
- Base contract (fully executed)
- All executed modifications (chronological)
- Government Acceptance Letters (ESPC)
- M&V Plan / Exhibit A
- Task Order documents (if applicable)
- SF-30 modifications

### Tab 03 — M&V Reports & Technical Review
- Current performance year M&V report
- COR comment logs with resolution tracking
- 30-day review clock documentation
- M&V Determination Memos
- Revised savings calculations
- FEMP M&V version compliance documentation

### Tab 04 — Payment & Financial
- Invoices (current and historical)
- Receiving Reports (RR) in EASi
- PPA compliance documentation
- Interest payment modifications
- Payment authorization memos
- PR documentation

### Tab 05 — Performance Evaluation & Correspondence
- CPARS evaluations (quarterly/annual per contract)
- Cure notices and vendor responses
- Touch notices (escalation documentation)
- Memoranda for Record (MFR)
- FEMP LOC contact updates
- Settlement documentation

### Tab 06 — Witnessing & Site Documentation
- Government witnessing forms (signed — GSA only)
- Witnessing schedules and confirmations
- Site visit documentation
- BAS/metering verification records

### Tab 07 — HSPD-12 & Personnel Security
- Active PIV card roster
- PIV card issue/return tracking
- Access card expiration tracking
- HSPD-12 follow-up correspondence
- zoned-hspd12@gsa.gov communication log

### Tab 08 — Special Items & Closeout
- Settlement files and analysis
- Partial termination documentation
- Government Impact Action Plans
- Closeout plans and timelines
- Contract Completion Statements
- Final payment documentation

## Compliance Checkpoints

| Requirement | Authority | Frequency |
|-------------|-----------|-----------|
| COR file completeness review | PIB 21-05 | Quarterly |
| CPARS evaluation | FAR 42.1501 | Per contract schedule |
| PPA compliance verification | FAR 32.904 | Each invoice cycle |
| HSPD-12 roster review | HSPD-12 / OIG A240046 | Monthly |
| M&V report 30-day clock | PIB 18-02 | Each report submission |
| Mod execution tracking | FAR 1.602-2 | Continuous |
