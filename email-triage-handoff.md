```
    ├─► Is it for a Zone 7 contract?
    │       │
    │       ├─► YES → Verify CLIN/pricing → Create RR in EASi → Upload 3025
    │       │
    │       └─► NO → Forward to correct COR
    │
    └─► Does Pegasys validation fail?
            │
            ├─► YES → Email Tamira Mitchell for manual processing
            │
            └─► NO → Standard processing continues
```

### M&V Report Received

```
M&V Report Received
    │
    ├─► Acknowledge receipt within 24 hours
    │
    ├─► Is report complete (all ECMs, correct period)?
    │       │
    │       ├─► YES → Begin technical review
    │       │
    │       └─► NO → Request corrections from contractor
    │
    └─► Technical review complete?
            │
            ├─► Comments needed → Send to contractor
            │
            └─► Approved → Accept in EASi, file, notify CO
```
