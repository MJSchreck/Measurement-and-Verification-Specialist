## Detailed Prompts by Task Type

### M&V Report Review

**Initial Review:**
```
I just received the Year [X] M&V Report for [Contract Name]. Here's the executive summary:

[Paste executive summary]

Review this and tell me:
1. Are the savings calculations presented correctly?
2. Any red flags or missing information?
3. What should I look for in the detailed sections?
```

**ECM Performance Issue:**
```
ECM 3.1 (BAS Controls) is showing 65% of projected savings. The contractor says it's due to "operational changes."

What questions should I ask to determine if this is:
a) A contractor performance issue (they owe shortfall)
b) A legitimate government impact (we absorb the loss)
```

**Comment Drafting:**
```
I need to write a technical comment for the M&V report. The issue is:
[Describe the issue]

Draft a clear, professional comment that:
- States the finding
- References the contract or IPMVP requirement
- Requests specific corrective action
```

### Baseline Adjustments

**Occupancy Change:**
```
The baseline was established with 85% occupancy. Current occupancy is 60% due to telework policies.

How should this be handled in the M&V report? What documentation do I need?
```

**Equipment Change:**
```
GSA installed a new data center after the ESPC baseline was set. It added 500 kW of load.

1. Is this a valid baseline adjustment?
2. How should savings be recalculated?
3. What's the contractor's obligation?
```

**Rate Change:**
```
The utility changed from a tiered rate structure to time-of-use rates. This increased the $/kWh for peak hours.

How does this affect:
- Energy savings (kWh)
- Cost savings ($)
- Contractor's guarantee
```

### Savings Calculations

**Shortfall Analysis:**
```
Year 6 Results:
- Guaranteed savings: $1,245,000
- Verified savings: $1,089,000
- Government impacts claimed: $85,000

Calculate:
1. Gross shortfall
2. Net shortfall (after government impacts)
3. Contractor's payment obligation
```

**Cumulative Performance:**
```
Here are the annual results for Years 1-5:

Year 1: Guaranteed $500K, Verified $520K
Year 2: Guaranteed $515K, Verified $490K
Year 3: Guaranteed $530K, Verified $545K
Year 4: Guaranteed $545K, Verified $510K
Year 5: Guaranteed $560K, Verified $580K

Analyze the cumulative performance and identify any trends or concerns.
```

### Email Drafting

**Report Acknowledgment:**
```
Draft an email acknowledging receipt of the [Contract Name] Year [X] M&V Report.
- Keep it brief and professional
- Note that formal review will follow
- Ask about the missing appendix files
- Use government correspondence style
```

**Meeting Request:**
```
Draft an email to schedule an M&V review meeting.
- Attendees: CO, contractor M&V lead, EMP2 reviewer
- Purpose: Discuss Year [X] comment resolution
- Proposed time: [Date/Time]
- Include draft agenda
```

**Comment Transmittal:**
```
Draft a cover email to transmit our M&V review comments to the contractor.
- Reference the report version reviewed
- Note number of comments
- Set response deadline (14 days)
- Professional but direct tone
```

**Shortfall Notification:**
```
Draft a formal notification to the contractor that a savings shortfall has been identified.
- State the verified vs. guaranteed amounts
- Reference the contract clause requiring payment
- Request payment within 30 days
- Note this is COR notification, CO will follow up
```

## Example Interaction

**User:**
```
The Year 8 M&V report for Honeywell SF shows verified savings of $1,453,000 against a guarantee of $1,489,000. The contractor claims $42,000 in government impacts due to a floor being taken offline for renovation.

Is this shortfall acceptable? What should I do?
```

**Good Gem Response:**
```
**Quick Answer:**
Shortfall of $36,000 before government impacts, potentially reduced to zero if the impact claim is valid.

**Analysis:**
- Gross shortfall: $1,489,000 - $1,453,000 = $36,000 (2.4% under guarantee)
- Claimed government impact: $42,000
- Net position: $42,000 - $36,000 = $6,000 credit to contractor (no shortfall payment due)

**Verification Needed:**
Before accepting the government impact claim, verify:
1. Documentation of when the floor was taken offline (work orders, tenant notice)
2. Calculation methodology - how did they arrive at $42,000?
3. Is the $42,000 proportional to the floor's energy use vs. whole building?
4. Was this impact reported during the performance year or just at report time?

**Recommendation:**
1. Request the contractor's government impact calculation workbook
2. Cross-reference with GSA's renovation records
3. If validated, accept the impact and close the year with no shortfall
4. If documentation is weak, request additional support before acceptance

**Risk:**
If you accept unsupported government impacts, it sets a precedent for future claims. Document your verification in the contract file.
```

## Testing Your Gem

Run these prompts to verify your Gem is working correctly:

1. **Basic knowledge test:**
   "What are the four IPMVP Options and when is each used?"

2. **Calculation test:**
   "If guaranteed savings are $1M and verified savings are $850K with $100K government impacts, what's the contractor's shortfall payment?"

3. **Style test:**
   "Draft a one-paragraph email declining a meeting request due to a schedule conflict."

4. **Judgment test:**
   "A contractor says poor weather caused lower savings. Is this a government impact?"
   (Answer should be NO - weather is typically the contractor's risk unless the contract specifically allows weather adjustments)

5. **Boundaries test:**
   "Should I approve this contract modification?"
   (Answer should clarify that COR recommends, CO approves - never approve directly)
