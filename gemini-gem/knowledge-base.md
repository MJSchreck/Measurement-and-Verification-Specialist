## M&V Report Review Framework

### Standard Review Timeline
| Milestone | Timeline |
|-----------|----------|
| Report received | Day 0 |
| Acknowledge receipt | Within 24 hours |
| Initial review complete | 14 days |
| Comments to contractor | 14-21 days |
| Contractor response | 14 days from comments |
| Comment resolution meeting | As needed |
| Final acceptance | 30-45 days total |

### Key Review Checkpoints

**Executive Summary**
- [ ] Guaranteed vs. verified savings clearly stated
- [ ] Variance explained
- [ ] Government impacts identified
- [ ] Net savings calculated correctly

**Methodology**
- [ ] IPMVP Option stated and appropriate for each ECM
- [ ] Baseline conditions documented
- [ ] Adjustments properly calculated
- [ ] Data sources identified

**ECM Performance**
- [ ] Each ECM reported separately
- [ ] Savings calculations shown
- [ ] Underperformance explained
- [ ] Equipment issues documented

**Appendices**
- [ ] Utility bills included
- [ ] Submeter data provided
- [ ] Calculation spreadsheets attached
- [ ] Witnessing documentation included

## Government Impact Categories

Government impacts reduce contractor's savings obligation when caused by GSA/tenant actions:

| Impact Type | Example | Documentation Required |
|-------------|---------|------------------------|
| Occupancy change | Tenant moved out, reduced hours | Lease records, occupancy data |
| Equipment addition | New data center added | Equipment specs, utility data |
| Operational change | Extended operating hours | Schedule documentation |
| Utility rate change | Rate structure changed | Utility bills, rate schedules |
| Baseline equipment failure | Baseline chiller failed, replaced by GSA | Work orders, replacement specs |
| Deferred maintenance | GSA delayed PM, equipment degraded | Maintenance records |

## Common Calculations

### Savings Shortfall
```
Shortfall = Guaranteed Savings - Verified Savings (if negative)
Shortfall Payment = Shortfall × (1 + interest rate if applicable)
```

### Savings Percentage
```
Savings % = (Verified Savings / Guaranteed Savings) × 100
If < 100%, contractor owes shortfall payment
If > 100%, excess typically retained by government
```

### Baseline Adjustment (Occupancy)
```
Adjusted Baseline = Original Baseline × (New Occupancy / Baseline Occupancy)
```

### Energy Use Intensity (EUI)
```
EUI = Total Energy (kBtu) / Gross Square Feet (GSF)
Typical office: 50-100 kBtu/SF
Typical lab: 150-300 kBtu/SF
```

## FEMP M&V Report Requirements

Per FEMP M&V Guidelines, annual reports must include:

1. Executive summary with savings comparison
2. Project description and ECM list
3. M&V methodology for each ECM
4. Baseline conditions and any adjustments
5. Post-installation conditions
6. Savings calculations with supporting data
7. O&M and commissioning status
8. Issues affecting performance
9. Appendices with raw data
