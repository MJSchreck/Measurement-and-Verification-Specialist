# ESPC/UESC Payment Process Framework - Region 9

> **Source:** Notion page `1ae6badbd60680549070c7177c8078df`
> **Snapshot:** April 16, 2026

---

## Resilient Infrastructure

- **Project Quality Assurance:**
  - Contractor's ECM Commissioning Reports
  - 30-day performance verification
  - Post-installation documentation
  - Quality inspection protocols
  - As-built drawings maintenance
- **Long-term Sustainability:**
  - Performance Assurance Plan requirements
  - Operations work procedures
  - Preventive maintenance protocols
  - O&M manuals and spare parts tracking
  - Staff training documentation

## Efficiency Measures

- **Energy Conservation Measures (ECMs):**
  - Building automation systems (PGH11)
  - Advanced metering systems (PGH12)
  - Electrical optimization (PGH13)
  - Retro-commissioning (PGH14)
  - HVAC optimization (PGH30)
- **Performance Tracking:**
  - Energy usage monitoring
  - Cost savings analysis
  - Implementation verification
  - Measurement & Verification (M&V)
  - Annual performance reviews

## Affordable Implementation

- **Payment Structure:**
  - Investment Grade Audit funding
  - Year Zero installation payments
  - Amortization schedule management
  - Principal and interest tracking
  - M&V cost allocation

> **Payment Processing Timeline:**
> - Create PR 3 months before due date
> - Award 2 months prior to payment
> - Process acceptance documentation
> - Validate accounting strings
> - Monitor compliance requirements

## Documentation Requirements

### Required Forms

- Invoice breakdowns by building
- Letter of acceptance
- TO schedule
- ASID breakdown
- ECM documentation

### Financial Codes

- Activity codes (PGA38/PGA39)
- Sub-object codes
- ASID assignments
- Building identifiers
- Project type codes

> **Best Practice:** Maintain color-coded building numbers in accounting string documentation for improved clarity and tracking efficiency.
