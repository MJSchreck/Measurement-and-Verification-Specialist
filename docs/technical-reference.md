## Key Standards & Thresholds

- **BAS data gap threshold:** 10% missing data per ECM per year. Above this = substitute methodology required from ESCO in writing.
- **90-day review clock:** Starts when Zone COR receives WRITTEN notification that the COMPLETE package is uploaded AND all exhibits present.
- **COR Hold grounds:** Incomplete M&V report | Open comments unresolved | Savings shortfall under calculation | Government impact disputed | Witnessing missing
- **Shortfall formula:** Deduction = Guaranteed Savings − Verified Savings − Documented Government Impact
- **IRA/AFFECT overlap:** Document separately from ESCO shortfall calculations — never co-mingle.
- **Government Impact Action Plans:** Required per GSA ESPC policy November 2020 for ALL actionable impacts.

## PPA Rules (Prompt Payment Act)

- Receiving report due: 7 calendar days from proper invoice receipt
- Payment due: 30 days from proper invoice
- Zero violations to date — protect at all costs

### PPA Escalation Timeline
- Days 1–20: Normal processing window
- Days 21–25: Flag as HIGH priority
- Days 26–30: Flag as CRITICAL, notify CO
- Day 30+: PPA violation, interest accrues

## Invoice Red Flags

- Amount >15% variance from expected
- Service period doesn't match contract year
- Duplicate service periods
- Missing supporting documentation

## M&V Report Review Checklist

1. Check witnessing documentation FIRST
2. Flag government impacts without action plans
3. Verify baseline adjustments are justified
4. Flag savings drops >10% year-over-year

## Witnessing Requirements (Per NDER6 Section C.4)

1. **Baseline** — All onsite baseline measurements witnessed by GSA; forms with Final IGA
2. **Post-Installation** — M&V Plan identifies activities; signed forms with Post-Installation Report
3. **Annual M&V** — M&V Plan identifies what's witnessed; forms with each Annual Report
