# PF / M&V / COR Crosswalk — Role Delineation & BPA Task Structure

> **DECISION RULE:** PF delivers computational analysis → M&V evaluates methodology and makes technical determination → COR acts on the determination. PF never makes methodology calls. M&V never runs first-pass calculations. COR never makes technical determinations.

---

## Role Definitions

### PF — Computation & Facilitation (EMP2 / FEDITC)
**OWNS:** Runs independent calculation checks against ESCO-reported savings. Populates comment logs with computational findings. Verifies prior comment disposition corrections. Facilitates review meetings and logistics. Drafts preliminary findings documents.

**DOES NOT:** Make methodology determinations. Decide whether savings are verified. Evaluate IPMVP compliance. Make the technical call on baseline adequacy.

### M&V — Methodology & Determination (Government Specialist)
**OWNS:** Evaluates M&V methodology including IPMVP option selection, baseline period adequacy, and adjustment factor derivations. Makes the final technical call: savings verified, under-reported, or over-reported. Assesses data integrity and determines impact of data gaps. Resolves methodology disputes. Final technical authority.

**DOES NOT:** Run first-pass calculation checks. Facilitate review logistics. Perform computational verification.

### COR — Contract Administration (Government)
**OWNS:** Receiving reports and invoice processing in EASi. HSPD-12 contractor access verifications. Contract scope decisions and document control. CO/COR administrative correspondence. Cure notice process management.

**DOES NOT:** Make technical M&V determinations. Run savings calculations. Evaluate IPMVP compliance.

---

## Handoff Flow

| Step | Owner | Action |
|------|-------|--------|
| 1 | PF | Runs independent calculation checks, populates comment log |
| 2 | PF → M&V | PF delivers draft comment log with computational findings |
| 3 | M&V | Reviews for methodology compliance, makes technical determination |
| 4 | M&V → COR | M&V delivers finalized technical position |
| 5 | COR | Acts on determination (transmits to CO, processes admin actions) |

## PF-to-M&V Boundary Examples

| Scenario | PF Does | M&V Does |
|----------|---------|----------|
| Annual M&V Report arrives | Runs independent calc checks, populates comment log (Task 2B) | Reviews methodology compliance, makes verified/not-verified determination |
| Escalation methodology dispute | Provides independent calculation verification (Task 2B) | Makes technical determination on methodology compliance |
| Data gap (e.g., chiller kW not trending) | No involvement | Determines impact on savings, assesses alternative data acceptability |
| Report resubmission after comments | Verifies computational corrections incorporated | Reviews only if PF flags unresolved methodology issues |
| Cure notice process | Task 2E support | No involvement (COR/CO administration) |

## The Real Boundary: Question Type, Not Task Number

| Question Type | Owner | Example |
|--------------|-------|---------|
| Did the ESCO apply this formula correctly? | PF | Checking arithmetic, unit conversions, data entry |
| Is this the right formula to use? | M&V | IPMVP option selection, baseline model specification |
| Does the regression fit the data? | **OVERLAP** | PF runs the regression; M&V decides if fit is adequate |
| Are the reported savings correct? | **OVERLAP** | PF verifies math; M&V verifies method produced right answer |
| Should we accept these savings? | M&V | Final determination — verified, under-reported, over-reported |
| What's the financial impact of the shortfall? | PF (Task 3B) | Computation based on M&V's determination |

**Operational Rule:** PF flags, M&V decides. When PF encounters a methodology question during computation, they document the finding and flag it for M&V review. When M&V needs numbers run, M&V directs PF to perform the computation under M&V's specifications.
