## 5-Phase Remediation Model

| Phase | Action | Timing |
|---|---|---|
| 1 -- Diagnosis | Pull full history, root cause, financial exposure | Weeks 1-2 |
| 2 -- Cure Notice | Matt technical basis memo -> CO issues cure notice | Weeks 3-4 |
| 3 -- Response Evaluation | AI pre-screen -> PF calc review -> Matt determination | Weeks 5-8 |
| 4 -- Resolution or Escalation | Accept cure / Reject -> termination | Weeks 8-12 |
| 5 -- Closure or Termination | Closure MFR or FAR termination execution | Weeks 12+ |

## Designation Criteria

- 2+ consecutive PYs of unaccepted M&V reports
- 2+ PYs of unresolved guaranteed savings shortfall
- Physical ECM system failure
- Active cure notice
- Partial/full termination proceedings
- Payment withheld 90+ days unresolved
