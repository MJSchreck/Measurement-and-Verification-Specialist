- [ ] Sign and return COR Designation Letter to CO
- [ ] Add to 01_Contract Docs in Google Drive
- [ ] Schedule kickoff meeting with CO

### Within First Week

- [ ] Meet with CO for contract-specific oversight requirements
- [ ] Obtain complete contract file from CO/predecessor COR
- [ ] Review contract and all modifications
- [ ] Identify current performance year and key dates
- [ ] Review QASP (Quality Assurance Surveillance Plan)

- [ ] Key personnel list
- [ ] HSPD-12/PIV card status
- [ ] Site access requirements

### 5. Handoff Items
- [ ] Predecessor COR notes
- [ ] Open action items
- [ ] Upcoming deadlines

## Recurring COR Duties (All Contracts)

### Monthly
- [ ] Invoice review and RR processing (within 7 days of receipt)
- [ ] Contractor performance check-in
- [ ] Update tracking files

### Quarterly
- [ ] Review quarterly M&V data (if applicable)
- [ ] HSPD-12 contractor access review
- [ ] CO status update

### Annually
- [ ] M&V report review and approval
- [ ] Government witnessing (per M&V plan)
- [ ] CPARS evaluation
- [ ] Complete annual ESPC/UESC training
- [ ] Send training certificate to CO
- [ ] QASP review and update (before option exercise)

### At Contract End
- [ ] Final inspection
- [ ] Final CPARS
- [ ] GFP return verification
- [ ] PIV card collection
- [ ] Final invoice payment verification
- [ ] Close-out documentation to ECF

## ESPC/UESC-Specific Duties (From Designation Letter)

1. **M&V Reports:** Review, comment, approve annual reports per OFM Instructional Memoranda
2. **Witnessing:** Sign off on all M&V activities in contract's M&V Plan
3. **Coordination:** Work with NCMMS coordinator and O&M CO on equipment maintenance
4. **Savings Impact:** Require ESCO review of any building activities affecting savings
5. **O&M Interface:** Ensure building O&M contractor follows ESCO procedures
6. **Training:** Complete annual ESPC/UESC training, send cert to CO
