## PROBLEM-SOLVING FRAMEWORKS

### The 131 Rule (Matt's Preferred Format)
```
1 PROBLEM: Clear problem statement with context
3 PATHWAYS: Distinct approaches with pros/cons
1 RECOMMENDATION: Specific action with rationale
```

### Decision Point Protocol
```
Instead of: "You could consider these options..."
Use: "Recommendation: [SPECIFIC ACTION]
     → YES to proceed as stated
     → NO to decline
     → DIFFERENT for alternative approach"
```

### Technical Analysis Structure
```
SITUATION: Current state + key data
ISSUE: Specific problem/gap/risk
ANALYSIS: Root cause + supporting evidence
OPTIONS: Evaluated alternatives
RECOMMENDATION: Preferred path + implementation steps
```

## SYSTEM-SPECIFIC WORKFLOWS

### EASi Receiving Report Processing
1. **Validation Check:** Match invoice to contract terms, performance period
2. **Supporting Docs:** M&V report, government witnessing memo, acceptance letter
3. **Amount Verification:** Calculate based on contract formula, check rounding
4. **Routing:** COR review → CO concurrence → Receiver approval
5. **Pegasys Handoff:** Monitor for validation errors, escalate to Tamira Mitchell if needed

### M&V Report Review
1. **Completeness Check:** All required sections per M&V Plan
2. **Data Validation:** Meter readings, weather normalization, operational adjustments
3. **Savings Calculation:** Verify methodology, check arithmetic, compare to guarantee
4. **Baseline Adjustments:** Document government impacts, approve if justified
5. **Acceptance Decision:** Accept, Accept with Comments, or Reject with specific deficiencies

### Government Witnessing Protocol
1. **Pre-Visit:** Review test plans, coordinate with contractor, notify facility
2. **On-Site:** Document testing procedures, verify equipment specs, photograph installations
3. **Post-Visit:** Draft witnessing memo within 48 hours, upload to contract file
4. **Follow-up:** Track deficiency corrections, schedule re-witnessing if needed

### CPARS Evaluation Process
1. **Performance Period:** Typically annual, align with M&V reporting cycle
2. **Evaluation Areas:** Technical quality, schedule, management, small business, regulatory
3. **Rating Scale:** Exceptional, Very Good, Satisfactory, Marginal, Unsatisfactory
4. **Documentation:** Cite specific incidents, M&V results, correspondence
5. **Timeline:** Complete within 120 days of performance period end

## TECHNICAL REFERENCE QUICK-HITS

### Common ECM Types & Savings Ranges
- **LED Lighting Upgrades:** 50-75% energy reduction
- **VFD on HVAC:** 20-40% fan/pump energy reduction
- **Building Controls (BAS/EMS):** 10-30% whole building savings
- **Chiller Replacements:** 0.5-0.7 kW/ton → 0.3-0.5 kW/ton
- **Envelope (roof/windows):** 5-15% heating/cooling load reduction

### M&V Plan Options (IPMVP)
- **Option A:** Retrofit isolation, key parameter measurement
- **Option B:** Retrofit isolation, all parameter measurement
- **Option C:** Whole facility (most common for ESPC)
- **Option D:** Calibrated simulation

### Payment Structure Components
- **Implementation Phase:** Progress payments tied to milestones
- **Performance Period:** Annual debt service + TRM operations
- **Completion Payment:** Final payment after verification
- **Bonus/Penalty:** Based on performance vs. guarantee

### Baseline Adjustment Triggers
- **Government Directive:** Policy change affecting operations
- **Capital Project:** Non-ESCO upgrade impacting baseline
- **Space Change:** Occupancy increase/decrease >10%
- **Weather:** Significant deviation from TMY3 data
