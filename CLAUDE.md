## Key Workflows

### 1. Annual M&V Report Review

**Timeline:** Reports due 90 days after performance year end

**Review Checklist:**
- [ ] Verify baseline calculations match IGA (Investment Grade Audit)
- [ ] Check routine adjustments (weather normalization, occupancy)
- [ ] Validate non-routine adjustments (equipment changes, schedule modifications)
- [ ] Confirm metering data quality and completeness
- [ ] Review savings calculations by ECM
- [ ] Identify deficiencies (HW-responsible vs GSA-responsible)
- [ ] Calculate net payable amount
- [ ] Document CO concerns for response

**Deficiency Classification:**
- **HW (Contractor) Deficiency:** Impacts guarantee payment - contractor pays shortfall
- **GSA (Government) Deficiency:** Operational issues - no contractor penalty but lost savings
- **As-Built Impact:** Permanent reduction from construction differences

### 2. Payment Processing (EASI)

**Formula:**
```
Net Payable = Verified Savings - HW Deficiencies - Shortfall Deduction
```

**Required Documentation:**
- Signed M&V report (acceptance letter)
- Deficiency summary with dollar impacts
- Receiving report
- Invoice from contractor

## IPMVP Reference

**Options Used in Portfolio:**
- **Option A (Partially Measured):** Lighting, water fixtures - stipulated factors with spot measurements
- **Option B (Retrofit Isolation):** HVAC equipment - continuous metering of specific systems
- **Option C (Whole Facility):** Building-level utility analysis with regression modeling
- **Option D (Simulation):** Calibrated energy models - rarely used post-construction

**Key Calculations:**
```
Savings = (Baseline Energy - Post-Installation Energy) ± Adjustments

Baseline = f(weather, occupancy, operating hours) from pre-retrofit period
Adjustments = Routine (weather) + Non-Routine (equipment, schedule changes)
```

**Uncertainty Requirements:**
- ASHRAE Guideline 14: ±10% savings at 68% confidence for Option C
- FEMP: ±25% savings at 90% confidence acceptable for most projects

## Common Tasks - How to Help

### "Analyze this M&V report"
1. Extract key metrics (verified savings, guarantee, shortfall)
2. Identify all deficiencies by ECM and responsible party
3. Flag any issues requiring CO attention
4. Calculate net payable amount
5. Compare to prior year performance

### "Draft acceptance letter"
Include:
- Performance year and report date
- Verified savings vs guarantee
- Shortfall amount and cumulative total
- Outstanding deficiencies requiring correction
- Payment authorization language
- Deadline for shortfall payment (typically 30 days)

### "Create deficiency tracker"
Format as table with:
- Building, ECM number, ECM type
- Issue description
- Dollar impact (current year)
- Responsible party (HW/GSA)
- Status (Unresolved/Resolved/Partial)
- CO comments if any
- Historical trend (Y1-current)

### "Calculate payback/projections"
- Simple payback = Implementation Cost / Annual Verified Savings
- Project cumulative shortfall at current trend
- Apply escalation rates (2.3% electric, 3.9% gas, 3.5% water)

### "Prepare CO briefing"
- Executive summary (1 paragraph)
- Performance vs guarantee (current year + cumulative)
- Top 5 issues by dollar impact
- Recommended actions
- Risk assessment for remaining contract term
