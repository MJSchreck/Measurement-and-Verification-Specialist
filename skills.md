# Skills and Competencies

## Technical Skills

### Core M&V Competencies

| Skill | Description | Proficiency Level |
|-------|-------------|-------------------|
| IPMVP Application | Apply IPMVP Options A, B, C, and D appropriately based on project requirements | Expert |
| Baseline Development | Establish accurate energy baselines using historical consumption data | Expert |
| Savings Calculations | Calculate gross and net energy savings with proper adjustments | Expert |
| Statistical Analysis | Apply regression analysis, uncertainty analysis, and statistical validation | Advanced |
| M&V Plan Development | Create comprehensive M&V plans meeting industry standards | Expert |

### Data Analysis and Modeling

| Skill | Description | Proficiency Level |
|-------|-------------|-------------------|
| Regression Modeling | Develop single and multivariate regression models for energy prediction | Advanced |
| Time Series Analysis | Analyze interval data and identify consumption patterns | Advanced |
| Weather Normalization | Adjust energy data for weather variables using degree days and TMY data | Advanced |
| Utility Bill Analysis | Interpret utility bills and rate structures for accurate cost savings | Intermediate |
| Data Validation | Identify anomalies, gaps, and errors in energy data | Advanced |

## Skill Development Path

### Entry Level (0-2 years)

- Master fundamental M&V concepts and IPMVP basics
- Develop proficiency in Excel and data analysis
- Learn building systems fundamentals
- Assist senior staff with M&V plan development
- Gain field experience with metering equipment

### Mid Level (2-5 years)

- Lead M&V plan development for standard projects
- Develop advanced statistical analysis skills
- Obtain CMVP certification
- Manage multiple concurrent M&V projects
- Mentor junior staff members

### Senior Level (5+ years)

- Design complex M&V approaches for large portfolios
- Develop custom analysis tools and methodologies
- Provide expert testimony and dispute resolution
- Lead program-level evaluation efforts
- Contribute to industry standards development

## Continuous Learning

M&V Specialists should stay current with:

- Updates to IPMVP and ASHRAE Guideline 14
- Emerging technologies (IoT sensors, machine learning for M&V)
- New building codes and energy efficiency standards
- Advanced analytics and modeling techniques
- Industry conferences (AEE World, IEPEC, ACEEE Summer Study)
