# M&V Analysis Prompt Template

## Standard M&V Report Analysis

When analyzing an M&V report, extract and summarize:

1. **Performance Period**
   - Start/end dates
   - Performance Year number

2. **Savings Summary**
   - Guaranteed savings (contracted)
   - Reported savings (actual)
   - Variance (shortfall or surplus)

3. **ECM-Level Breakdown**
   - List each Energy Conservation Measure (ECM)
   - Guaranteed vs. actual for each
   - Root cause for any shortfalls

4. **Baseline Adjustments**
   - Any adjustments claimed
   - Justification provided
   - Whether adjustments are valid per IPMVP

5. **Action Items**
   - Issues requiring COR attention
   - Requests from ESCO
   - Deadlines or due dates

## Example Query

```
Analyze the attached M&V report and provide:
1. One-paragraph executive summary
2. Table of ECM performance (guaranteed vs actual)
3. List of shortfalls with root causes
4. Recommended next steps for COR
```
